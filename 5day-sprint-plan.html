Section 01

The 3-Tier Message Classifier

Every inbound message passes through 3 gates in sequence. Only messages that fail the first two gates reach the LLM. This protects your margins at scale without degrading the user experience.

⚡ Tier 1 — Exact Match ~₹0 per message
Pure string matching. No AI. Handles approval responses (button taps), session continuations, and known command shortcuts that users learn over time. Resolved in <5ms.
"1" → approve "2" → reject "hi" → greeting "help" → menu "stop" → unsubscribe Button tap callbacks
Cost per message: ~₹0.00 — pure DB + string ops
No exact match → pass to Tier 2
🔍 Tier 2 — Keyword Classifier ~₹0.01 per message
Lightweight rule-based classifier. Checks for intent-bearing keywords and patterns using regex + a small lookup table. Extracts entities (product name, customer name, amount) using simple NER. No LLM call. Handles ~60% of all production messages once users are familiar.
"stock [product]" "dues [customer]" "invoice [name] ₹[amount]" "how many [product]" "outstanding [customer]" "balance [customer]"
Cost per message: ~₹0.01 — Redis lookup + regex only
Ambiguous / no keyword match → pass to Tier 3
🧠 Tier 3 — LLM (Claude Sonnet) ~₹0.50–1.50 per message
Full natural language understanding. Handles first-time users, ambiguous phrasing, multi-entity requests, typos, and anything the keyword classifier can't confidently resolve. Returns structured intent JSON. Also used for response composition on complex outputs.
"Arey yaar Mehta ka kitna bacha hai?" "Get me an invoice for that last client" "Show me what's low on stock" New user, first message Compound requests
Cost per message: ₹0.50–1.50 — Claude API tokens

# ── TIER 1: EXACT MATCH ──────────────────────────────
EXACT_MAP = {
    "1": "action:approve",
    "2": "action:reject",
    "hi": "action:greet",
    "help": "action:menu",
    "stop": "action:unsubscribe",
}

def tier1_exact(text: str) -> str | None:
    return EXACT_MAP.get(text.strip().lower())


# ── TIER 2: KEYWORD CLASSIFIER ───────────────────────
import re

KEYWORD_RULES = [
    {
        "intent": "check_stock",
        "patterns": [r"stock\s+(.+)", r"how many\s+(.+)",
                       r"kitna\s+(.+) hai", r"(.+)\s+available"],
        "entity": "product"
    },
    {
        "intent": "check_outstanding",
        "patterns": [r"dues?\s+(.+)", r"outstanding\s+(.+)",
                       r"balance\s+(.+)", r"(.+)\s+ka bacha"],
        "entity": "customer"
    },
    {
        "intent": "create_invoice",
        "patterns": [r"invoice\s+(.+)\s+₹?([\d,]+)",
                       r"bill\s+(.+)\s+₹?([\d,]+)"],
        "entity": "customer+amount"
    },
]

def tier2_keyword(text: str) -> dict | None:
    t = text.strip().lower()
    for rule in KEYWORD_RULES:
        for pattern in rule["patterns"]:
            m = re.search(pattern, t)
            if m:
                return {
                    "intent": rule["intent"],
                    "entity_raw": m.group(1).strip(),
                    "tier": 2,
                    "confidence": 0.85
                }
    return None


# ── TIER 3: LLM FALLBACK ─────────────────────────────
async def tier3_llm(text: str, user_ctx: dict) -> dict:
    # Only called when Tier 1 + 2 both return None
    prompt = f"""You are an intent parser for {user_ctx['org_name']}.
Extract intent and entities from this message.
Allowed intents: check_stock, create_invoice, check_outstanding, unknown
Return ONLY valid JSON: {{"intent": "...", "entities": {{}}, "confidence": 0.0}}

Message: {text}"""
    response = await claude.complete(prompt)
    return parse_json(response) | {"tier": 3}


# ── MAIN ROUTER ──────────────────────────────────────
async def classify_message(text: str, user_ctx: dict) -> dict:
    # Tier 1 — free
    t1 = tier1_exact(text)
    if t1: return {"intent": t1, "tier": 1, "cost": 0}

    # Tier 2 — near-free
    t2 = tier2_keyword(text)
    if t2: return t2 | {"cost": 0.01}

    # Tier 3 — LLM (last resort)
    t3 = await tier3_llm(text, user_ctx)
    return t3 | {"cost": 1.50}
