=== JEWELLERY INDUSTRY — DOMAIN GLOSSARY & EXAMPLES ===

HINGLISH GLOSSARY (what users say → what it means in DB):

"baaki" / "udhaar" / "kitna baaki" / "pending amount" / "dues" / "outstanding"
  → invoices WHERE status IN ('pending', 'overdue')

"bhav" / "rate" / "sone ka bhav" / "aaj ka bhav" / "gold rate" / "chandi rate"
  → pricing WHERE quotation_number IS NULL (these are the base rates)

"maal" / "inventory" / "stock" / "khatam ho raha" / "order karna padega"
  → inventory table

"production mein" / "kaam chal raha hai" / "ban raha" / "in production"
  → orders WHERE status = 'in_production'

"ready hai" / "ready orders" / "delivery ke liye" / "collect karne"
  → orders WHERE status = 'ready'

"low stock" / "stock kam" / "khatam hone wala" / "reorder"
  → inventory WHERE qty <= reorder_level ORDER BY (reorder_level - qty) DESC

DOCUMENT NUMBER PATTERNS: INV-XXXX (invoices), ORD-XXXX (orders), QUO-XXXX (quotations)
METAL TYPES: 22kt, 18kt, 14kt, silver, platinum
PRICING TABLE: quotation_number IS NULL = base metal rates. quotation_number IS NOT NULL = saved quotations.

ORDER STATUS FLOW: confirmed → in_production → quality_check → ready → delivered

AMOUNT FORMAT: Rs.1,45,000 — NOT ₹1,45,000 — NOT Rs.145000

CUSTOMER DISAMBIGUATION EXAMPLES:

  Extract: customer = "Mehta Enterprises"
  Query: SELECT id,name,city FROM customers WHERE org_id=$1 AND name ILIKE '%Mehta Enterprises%'
  Result: 1 row → Mehta Enterprises (Pune) → proceed immediately

Example 2 — Short form given → clarify if multiple matches:
  User: "Mehta ka baaki"

  Result: 3 rows → call clarify tool with all 3 options

Example 3 — Full name, 2 words → 1 result → proceed:
  User: "Singh Bullion ka outstanding"
  Extract: customer = "Singh Bullion"
  Query: ILIKE '%Singh Bullion%' → 1 result (Singh Bullion Mart) → proceed

Example 4 — Specific with amount → ACTION (create):
  User: "Jain Gold Works 45000 invoice"
  Interpret as: CREATE invoice for Jain Gold Works, amount = 45000
  Steps: resolve customer → confirm_action → create

INVOICE QUERIES (existing invoices):
SELECT i.invoice_number, c.name as customer_name, c.city, i.amount, i.status, i.due_date
FROM invoices i JOIN customers c ON c.id = i.customer_id
WHERE i.org_id = $1 [AND conditions]
Always JOIN customers table so PDFs show customer names.

OUTSTANDING / DUES QUERY PATTERN:
SELECT i.invoice_number, c.name as customer_name, c.city, c.gst_number,
       i.amount, i.status, i.due_date
FROM invoices i JOIN customers c ON c.id = i.customer_id
WHERE i.org_id = $1 AND i.status IN ('pending', 'overdue')
[AND c.name ILIKE $2 for specific customer]
ORDER BY i.due_date ASC

ORDERS ACTIVE STATUS ARRAY: ARRAY['confirmed','in_production','quality_check','ready']

QUOTATION GENERATION FLOW — 4 REQUIRED INPUTS:

REQUIRED (call clarify if ANY is missing):
  1. customer_name  — who the quote is for (lookup customers table)
  2. design_code    — inventory SKU, format: GC-22K-001, DP-18K-001, SA-SLV-001 etc.
  3. weight_grams   — weight in grams (numeric, e.g. 15.5 or "15.5g")
  4. metal_type     — 22kt / 18kt / 14kt / silver / platinum

STEP 1 — CHECK INPUTS: If any of the 4 are missing, immediately call clarify.
  Example: User says "quote Mehta 15g" → missing design_code AND metal_type
  → call clarify: "To generate the quote I need: design code (SKU) and metal type
    (22kt/18kt/14kt/silver). Which design and metal?"

STEP 2 — RESOLVE CUSTOMER (two-pass as usual):
  SELECT id, name, city FROM customers WHERE org_id = $1 AND name ILIKE $2

STEP 3 — LOOKUP DESIGN BY SKU:
  SELECT sku, name FROM inventory WHERE org_id = $1 AND sku = $2
  (exact match on sku column — case-insensitive: UPPER($2))
  If SKU not found: ask user to check the design code and try again.

STEP 4 — FETCH METAL RATE:
  SELECT rate_per_gram, making_charge_pct FROM pricing
  WHERE org_id = $1 AND metal_type = $2 AND quotation_number IS NULL

STEP 5 — FETCH GST RATE:
  SELECT gst_rate FROM orgs WHERE id = $1

STEP 6 — CALCULATE (do this mentally — do not query DB for arithmetic):
  metal_cost     = weight_grams × rate_per_gram
  making_charges = metal_cost × making_charge_pct / 100
  subtotal       = metal_cost + making_charges
  gst_amount     = subtotal × gst_rate / 100
  total_amount   = subtotal + gst_amount
  (round all to 2 decimal places)

STEP 7 — CONFIRM ACTION:
  action_description = "Generate Price Quotation for [customer_name]"
  details = {{
    "Customer": customer_name + " (" + city + ")",
    "Design": design_name + " [" + design_code + "]",
    "Metal": metal_type.upper() + " @ Rs." + rate_per_gram + "/g",
    "Weight": weight_grams + "g",
    "Metal Cost": "Rs." + metal_cost (Indian format),
    "Making (" + making_pct + "%)": "Rs." + making_charges,
    "GST (" + gst_rate + "%)": "Rs." + gst_amount,
    "TOTAL": "Rs." + total_amount
  }}

STEP 8 — GENERATE PDF (after user says yes):
  Call generate_pdf with:
    doc_type     = "quotation"
    rows         = []           ← always empty for quotation
    title        = "Price Quotation — [customer_name]"
    subtitle     = "[metal_type.upper()] [weight_grams]g — [design_code]"
    extra_context = {{
      "customer_name":       <from customer lookup>,
      "customer_city":       <from customer lookup>,
      "customer_gstin":      <from customer lookup — gst_number field>,
      "design_code":         <the SKU>,
      "design_name":         <from inventory.name>,
      "metal_type":          <e.g. "22KT">,
      "weight_grams":        <float>,
      "rate_per_gram":       <float>,
      "making_charge_pct":   <float>,
      "metal_cost":          <calculated>,
      "making_charges":      <calculated>,
      "subtotal":            <calculated>,
      "gst_pct":             <from orgs.gst_rate>,
      "gst_amount":          <calculated>,
      "total_amount":        <calculated>,
      "valid_days":          3
    }}

  NOTE: quotation_number is auto-generated inside generate_pdf. Do NOT query for it.

QUOTATION DISAMBIGUATION:
  "quote Mehta GC-22K-001 15g 22kt" → customer="Mehta" (could be 3 Mehtas → clarify)
  "quote Mehta Enterprises GC-22K-001 15g 22kt" → 1 match → proceed
